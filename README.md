# Pot Making in Blender

This project demonstrates a 3D model of a clay pot created using Blender. It includes the `.blend` file, a rendered image, and an animation video showing the pot creation process.

## 🛠 Tools Used
- Blender 4.1
- Cycles Renderer

## 📁 Files Included
- `pot_model.blend`: Blender file of the pot.
- `renders/pot.png`: Final rendered image.
- `renders/001-050.mkv`: Animation showing the pot being formed.

## 🔄 Render Instructions
To re-render the scene, open the `.blend` file in Blender and press `F12` for image render or `Ctrl + F12` for animation render.
